# Texas Hold'em Monte Carlo Simulator

Interactive No-Limit Texas Hold'em simulator with 2–9 seats, visual 52-card deck picker, community board setup, live-tunable player archetypes (`Calling Station`, `Aggressive`, `Nit`, `TAG`, `Maniac`, `Showdown`), up to 100,000-hand Monte Carlo runs, EV/equity comparison, and play-by-play hand histories.
